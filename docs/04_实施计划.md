## 4. 验收必须能失败

- 零阶段执行、未知阶段、旧产物时间/哈希不匹配：runner 失败。
- 关键来源未审阅、必需 IR op 不支持、参数未解析：generation blocked。
- compile/elaborate/run/export 任一步失败：run invalid，不能变成“0% coverage”。
- 事件对拍失败、native count 与 witness 无法核对：模型或数据 gate 失败。
- 修复后新增 checker 故障或无关目标退化：修复拒收，并保存反例。
- 无进展或预算用尽：stalled/budget_exhausted；不会自动产生 unreachable。
- 目标、约束或 DUT 版本变了：旧 closure 失效，列出最小重跑集合。

首版用固定目标集做回归。目标语义确需修正时产生新的 scope/plan 版本，报告旧新目标集合差异，并对基线重新评测；不能在一次曲线中悄悄换分母。
